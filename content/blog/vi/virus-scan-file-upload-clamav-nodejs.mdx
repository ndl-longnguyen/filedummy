Cho phép người dùng tải lên các tài liệu và archive tùy ý tạo ra trách nhiệm bảo mật nghiêm trọng. ClamAV là một engine diệt virus mã nguồn mở có khả năng phát hiện virus, trojan, macro độc hại và zip bomb theo thời gian thực.

## Kiến Trúc Triển Khai ClamAV

Kiến trúc production được khuyến nghị chạy `clamd` (ClamAV daemon) như một container độc lập hoặc dịch vụ Unix socket cục bộ, giao tiếp với ứng dụng Node.js qua cổng TCP 3310 hoặc Unix IPC.

```
[Upload Người Dùng] --> [Node.js API Server] --(INSTREAM qua TCP 3310)--> [ClamAV Daemon (clamd)]
                              |
                              +--> Nếu Sạch: Lưu vào S3/R2
                              +--> Nếu Bị Nhiễm: Cách ly & Ghi Log Cảnh Báo Bảo Mật
```

## Tích Hợp Với Node.js Qua clamscan

```bash
npm install clamscan
```

```typescript
import NodeClam from 'clamscan';

let clamScanInstance: NodeClam | null = null;

async function getClamScanner(): Promise<NodeClam> {
  if (clamScanInstance) return clamScanInstance;

  clamScanInstance = await new NodeClam().init({
    clamdscan: {
      host: process.env.CLAMAV_HOST || '127.0.0.1',
      port: Number(process.env.CLAMAV_PORT) || 3310,
      timeout: 60000,
    },
    preference: 'clamdscan',
  });

  return clamScanInstance;
}

export async function scanUploadedBuffer(fileBuffer: Buffer): Promise<{ isInfected: boolean; viruses: string[] }> {
  const scanner = await getClamScanner();
  const { isInfected, viruses } = await scanner.scanBuffer(fileBuffer);

  if (isInfected) {
    console.warn('PHÁT HIỆN PHẦN MỀM ĐỘC HẠI TRONG UPLOAD:', viruses);
  }

  return { isInfected, viruses };
}
```

## Xử Lý Quét Theo Kiểu Bất Đồng Bộ
Quét tệp lớn mất 1–5 giây. Với các tệp trên 50MB:
1. Lưu tệp với trạng thái `PENDING_SCAN` trong object storage.
2. Phát một sự kiện quét vào hàng đợi công việc nền (ví dụ: BullMQ / AWS SQS).
3. Cập nhật trạng thái tệp thành `ACTIVE` hoặc `REJECTED` sau khi ClamAV hoàn thành đánh giá.
