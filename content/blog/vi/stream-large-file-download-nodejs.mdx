Phục vụ tệp lớn trực tiếp từ Node.js mà không có CDN hoặc proxy object storage đòi hỏi phải sử dụng streaming. Tải một tệp 1GB vào bộ nhớ bằng `fs.readFileSync` sẽ tiêu tốn 1GB RAM máy chủ cho mỗi người dùng kết nối — nhanh chóng dẫn đến crash tiến trình.

## Streaming Tệp Với HTTP Streams Của Node.js

Readable stream của Node.js chỉ buffer một lượng nhỏ chunk (thường là 64KB) trong bộ nhớ tại bất kỳ thời điểm nào:

```typescript
import http from 'http';
import fs from 'fs';
import path from 'path';

const server = http.createServer((req, res) => {
  const filePath = path.join(process.cwd(), 'files', 'large-dataset.pdf');

  fs.stat(filePath, (err, stats) => {
    if (err) {
      res.writeHead(404, { 'Content-Type': 'text/plain' });
      return res.end('Không tìm thấy tệp');
    }

    // Thiết lập header response nhị phân
    res.writeHead(200, {
      'Content-Type': 'application/pdf',
      'Content-Length': stats.size,
      'Content-Disposition': 'attachment; filename="large-dataset.pdf"',
      'Accept-Ranges': 'bytes',
    });

    const readStream = fs.createReadStream(filePath);

    // Tự động xử lý TCP backpressure
    readStream.pipe(res);

    // Xử lý khi client ngắt kết nối
    req.on('close', () => {
      readStream.destroy();
    });
  });
});

server.listen(3000, () => console.log('Máy chủ tải xuống đang chạy trên cổng 3000'));
```

## Hiểu Stream Backpressure
Khi máy chủ có thể đọc từ đĩa nhanh hơn tốc độ client nhận dữ liệu qua mạng, `stream.pipe(res)` tự động tạm dừng read stream cho đến khi buffer socket drain của client được giải phóng, giúp bảo toàn bộ nhớ máy chủ.
