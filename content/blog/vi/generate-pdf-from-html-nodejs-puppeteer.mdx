## Render HTML Sang PDF Với Puppeteer

```typescript
import puppeteer from 'puppeteer';

export interface PdfRenderOptions {
  htmlContent: string;
  outputPath?: string;
  format?: 'A4' | 'Letter';
}

export async function generatePdfFromHtml({
  htmlContent,
  outputPath,
  format = 'A4',
}: PdfRenderOptions): Promise<Buffer> {
  const browser = await puppeteer.launch({
    headless: true,
    args: ['--no-sandbox', '--disable-setuid-sandbox'], // Bắt buộc trong container Linux Docker
  });

  try {
    const page = await browser.newPage();

    // Đặt nội dung HTML và chờ đến khi kết nối mạng ổn định
    await page.setContent(htmlContent, { waitUntil: 'networkidle0' });

    const pdfBuffer = await page.pdf({
      format: format,
      printBackground: true, // Quan trọng để hiển thị nền và màu sắc CSS
      margin: {
        top: '20mm',
        right: '15mm',
        bottom: '20mm',
        left: '15mm',
      },
      path: outputPath,
    });

    return Buffer.from(pdfBuffer);
  } finally {
    await browser.close();
  }
}
```

## Quy Tắc CSS Cho PDF In Ấn
- **Sử dụng CSS `@page`:** Kiểm soát kích thước giấy và lề với CSS tiêu chuẩn:
  ```css
  @page {
    size: A4 portrait;
    margin: 1.5cm;
  }
  ```
- **Tránh chia tách ngắt trang:** Ngăn bảng biểu và tiêu đề bị chia nhỏ qua các trang bằng `page-break-inside: avoid;`.
