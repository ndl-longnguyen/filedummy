Kiểm thử tải endpoint tải xuống tệp đảm bảo rằng CDN, các quy tắc edge caching và máy chủ object storage origin của bạn xử lý được các đợt tăng đột biến đồng thời mà không bị giới hạn băng thông hoặc tỷ lệ lỗi cao. Hướng dẫn này trình bày cách xây dựng load test bằng Grafana k6 và Apache JMeter.

## Viết Load Test Tải Xuống Tệp Với Grafana k6

k6 là công cụ load test hiện đại, thân thiện với lập trình viên, được viết bằng Go với script kiểm thử JavaScript.

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  stages: [
    { duration: '30s', target: 20 },  // Tăng dần lên 20 người dùng
    { duration: '1m', target: 50 },   // Duy trì 50 lượt tải xuống đồng thời
    { duration: '20s', target: 0 },   // Giảm dần
  ],
  thresholds: {
    http_req_duration: ['p(95)<1500'], // 95% request phải hoàn thành dưới 1,5 giây
    http_req_failed: ['rate<0.01'],    // Tỷ lệ lỗi phải dưới 1%
  },
};

export default function () {
  const url = 'https://filedummy.dev/api/download?type=pdf&size=10mb';
  const res = http.get(url, {
    responseType: 'binary',
  });

  check(res, {
    'mã trạng thái là 200': (r) => r.status === 200,
    'độ dài nội dung khớp': (r) => r.body.length === 10485760,
    'có header cache-control': (r) => r.headers['Cache-Control'] !== undefined,
  });

  sleep(1);
}
```

## Cấu Hình Apache JMeter Cho Load Test Tải Xuống

1. Tạo **Thread Group** với số lượng virtual user đồng thời mong muốn (ví dụ: 100 thread, thời gian ramp-up 30 giây).
2. Thêm sampler **HTTP Request** trỏ đến URL tải xuống của bạn.
3. Đánh dấu ô **Save response as MD5 hash** nếu bạn không muốn JMeter lưu trữ payload nhiều gigabyte trong bộ nhớ test runner.
4. Thêm **Response Assertion** kiểm tra HTTP 200 và header hợp lệ.

## Các Chỉ Số Cần Theo Dõi Trong Quá Trình Test Tải Xuống Tệp
- **Throughput (MB/s):** Tổng lưu lượng mạng egress từ origin hoặc CDN của bạn.
- **Time to First Byte (TTFB):** Làm nổi bật liệu việc tra cứu origin hay ký presigned URL có đang tạo ra bottleneck hay không.
- **Đột biến lỗi (HTTP 429 / 503):** Chỉ ra giới hạn tốc độ hoặc connection pool upstream bị bão hòa.
