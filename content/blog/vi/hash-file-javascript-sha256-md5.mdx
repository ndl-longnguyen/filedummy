Tính toán hash mật mã của tệp là nền tảng cho loại bỏ trùng lặp dữ liệu, xác minh giả mạo và kiểm tra tính toàn vẹn. Trình duyệt hiện đại cung cấp Web Crypto API hiệu năng cao cho SHA-256 và SHA-512, trong khi Node.js cung cấp module `crypto` gốc với hỗ trợ streaming.

## Tính Mã Băm Với Web Crypto API Trên Trình Duyệt

Web Crypto API chạy bên trong engine trình duyệt sử dụng các thao tác mật mã được tăng tốc phần cứng:

```typescript
export async function calculateFileSha256(file: File): Promise<string> {
  const arrayBuffer = await file.arrayBuffer();
  const hashBuffer = await crypto.subtle.digest('SHA-256', arrayBuffer);

  // Chuyển đổi ArrayBuffer sang chuỗi Hex
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hexHash = hashArray.map((b) => b.toString(16).padStart(2, '0')).join('');

  return hexHash;
}
```

## Truyền Luồng Tính Hash Trong Node.js (Tệp Lớn)

Khi hash các tệp nhiều gigabyte trong Node.js, việc tải toàn bộ tệp vào bộ nhớ bằng `fs.readFileSync` gây crash do hết bộ nhớ. Sử dụng streaming transform thay thế:

```typescript
import fs from 'fs';
import crypto from 'crypto';

export function getFileChecksum(filePath: string, algorithm = 'sha256'): Promise<string> {
  return new Promise((resolve, reject) => {
    const hash = crypto.createHash(algorithm);
    const stream = fs.createReadStream(filePath);

    stream.on('data', (chunk) => hash.update(chunk));
    stream.on('end', () => resolve(hash.digest('hex')));
    stream.on('error', (err) => reject(err));
  });
}
```

## Khi Nào Nên Dùng MD5 vs SHA-256
- **MD5:** Đã bị phá vỡ về mặt mật mã. **Không** dùng cho hash mật khẩu, chữ ký số hoặc kiểm tra bảo mật. Vẫn được sử dụng rộng rãi cho checksum không liên quan bảo mật, như xác minh ETag S3 của AWS và khóa cache tệp cục bộ.
- **SHA-256:** Khả năng chống va chạm mật mã mạnh. Tiêu chuẩn ngành cho phát hành phần mềm, tính toàn vẹn gói và giao dịch blockchain.
