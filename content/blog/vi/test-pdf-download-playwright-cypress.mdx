Xác minh tải xuống tệp trong bộ kiểm thử end-to-end (E2E) đảm bảo rằng các công cụ báo cáo, hóa đơn và tính năng xuất dữ liệu hoạt động đáng tin cậy trên các engine trình duyệt. Dưới đây là cách kiểm thử tải xuống tệp bằng Playwright và Cypress.

## Kiểm Thử Tải Xuống Tệp Trong Playwright

Playwright cung cấp hỗ trợ đầu cấp cho sự kiện download trình duyệt qua API `waitForEvent('download')`.

```typescript
import { test, expect } from '@playwright/test';
import fs from 'fs';
import path from 'path';

test('Xác minh sự kiện tải xuống PDF và kích thước tệp', async ({ page }) => {
  await page.goto('https://filedummy.dev/pdf/5mb');

  // Bắt đầu chờ sự kiện download trước khi nhấn nút kích hoạt
  const downloadPromise = page.waitForEvent('download');
  await page.click('button:has-text("Download 5MB PDF")');
  const download = await downloadPromise;

  // Xác thực tên file được đề xuất
  expect(download.suggestedFilename()).toBe('sample-5mb.pdf');

  // Lưu vào thư mục kiểm thử tạm
  const downloadPath = path.join('/tmp', download.suggestedFilename());
  await download.saveAs(downloadPath);

  // Kiểm tra tệp tồn tại trên đĩa và xác minh kích thước byte
  const stats = fs.statSync(downloadPath);
  expect(stats.size).toBe(5 * 1024 * 1024); // 5.242.880 byte
});
```

## Kiểm Thử Tải Xuống Tệp Trong Cypress

Trong Cypress, các tệp được tải xuống qua trình duyệt tự động được lưu vào thư mục `cypress/downloads`.

```javascript
describe('Kiểm Thử Tải Xuống PDF Với Cypress', () => {
  it('tải xuống và xác minh PDF 5MB', () => {
    cy.visit('https://filedummy.dev/pdf/5mb');
    cy.contains('button', 'Download 5MB PDF').click();

    // Xác minh tệp tồn tại trong đường dẫn download mặc định
    const filename = 'cypress/downloads/sample-5mb.pdf';
    cy.readFile(filename, 'binary', { timeout: 15000 }).should((buffer) => {
      expect(buffer.length).to.be.at.least(5000000);
    });
  });
});
```

## Các Lưu Ý Quan Trọng Khi Kiểm Thử Download E2E
- **Tránh chặn tải xuống trên headless browser:** Đảm bảo tùy chọn trình duyệt cho phép tải xuống tự động mà không hiển thị hộp thoại hệ thống.
- **Thời gian timeout đủ lớn:** Tải xuống tệp lớn cần timeout rộng rãi trong môi trường CI nơi độ trễ mạng có thể biến động.
- **Dọn dẹp artifact:** Xóa các tệp đã tải xuống trong hook `afterEach` để tránh test runner hết dung lượng đĩa.
