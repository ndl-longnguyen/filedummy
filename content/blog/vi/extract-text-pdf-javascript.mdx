Trích xuất văn bản có cấu trúc từ PDF là thành phần cốt lõi của lập chỉ mục tìm kiếm, phân tích hóa đơn, LLM retrieval-augmented generation (RAG) và phân tích dữ liệu. Hướng dẫn này trình bày cách trích xuất văn bản thô và dữ liệu bố cục trong JavaScript và Node.js.

## Sử Dụng pdf-parse Trong Node.js

`pdf-parse` là thư viện Node.js nhẹ được xây dựng trên PDF.js của Mozilla:

```bash
npm install pdf-parse
```

```typescript
import fs from 'fs';
import pdf from 'pdf-parse';

export async function extractPdfText(filePath: string) {
  const dataBuffer = fs.readFileSync(filePath);

  const data = await pdf(dataBuffer);

  return {
    pageCount: data.numpages,
    text: data.text,
    info: data.info,
    metadata: data.metadata,
  };
}
```

## Trích Xuất Văn Bản Trên Trình Duyệt Với PDF.js

`pdfjs-dist` của Mozilla cho phép phân tích phía client mà không cần roundtrip đến máy chủ:

```typescript
import * as pdfjsLib from 'pdfjs-dist';

// Thiết lập nguồn worker
pdfjsLib.GlobalWorkerOptions.workerSrc = '//cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js';

export async function extractTextInBrowser(file: File): Promise<string> {
  const arrayBuffer = await file.arrayBuffer();
  const pdf = await pdfjsLib.getDocument({ data: arrayBuffer }).promise;
  let fullText = '';

  for (let i = 1; i <= pdf.numPages; i++) {
    const page = await pdf.getPage(i);
    const content = await page.getTextContent();
    const pageText = content.items.map((item: any) => item.str).join(' ');
    fullText += `--- Trang ${i} ---\n${pageText}\n\n`;
  }

  return fullText;
}
```

## Xử Lý Các Vấn Đề Thường Gặp Khi Trích Xuất Văn Bản
- **Bố cục hai cột:** Các bộ trích xuất đọc theo thứ tự stream có thể đọc ngang qua các cột thay vì đọc xuống.
- **Mã hóa font:** Các bảng mã hóa font nhúng không chuẩn có thể xuất ra các ký tự Unicode bị lỗi mà không có bảng ánh xạ ký tự phù hợp.
