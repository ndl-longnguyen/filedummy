Định dạng Tài liệu Di động (PDF), được Adobe tạo ra năm 1993 và sau đó được chuẩn hóa thành ISO 32000, được thiết kế để biểu diễn tài liệu độc lập với phần mềm ứng dụng, phần cứng và hệ điều hành. Hiểu cấu trúc object nội tại của nó rất quan trọng đối với các lập trình viên xây dựng trình phân tích PDF, công cụ tạo PDF tùy chỉnh và công cụ pháp chứng.

## 4 Vùng Vật Lý Của Tệp PDF

Mọi tệp PDF hợp lệ đều bao gồm bốn vùng vật lý chính:

```
+-------------------------------+
|  Header (%PDF-1.4)            |
+-------------------------------+
|  Body (Indirect Objects)      |
|    - Pages, Fonts, Streams    |
+-------------------------------+
|  Cross-Reference Table (xref) |
|    - Byte offsets of objects  |
+-------------------------------+
|  Trailer                      |
|    - Root pointer & %%EOF     |
+-------------------------------+
```

1. **Header (Tiêu đề):** Dòng đầu tiên xác định phiên bản đặc tả PDF (ví dụ: `%PDF-1.4`).
2. **Body (Thân):** Tập hợp các indirect object (từ điển, mảng, số và luồng nhị phân nén).
3. **Cross-Reference Table (Bảng tham chiếu chéo xref):** Bảng ánh xạ số object với byte offset chính xác từ đầu tệp. Điều này cho phép trình đọc PDF thực hiện random-access seeking mà không cần phân tích toàn bộ tệp tuần tự.
4. **Trailer:** Trỏ đến catalog dictionary (`Root`) và xác định byte offset của bảng `xref`, kết thúc bằng marker đặc biệt `%%EOF`.
