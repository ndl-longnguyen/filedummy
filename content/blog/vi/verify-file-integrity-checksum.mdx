Bất cứ khi nào bạn tải xuống các tệp nhị phân phần mềm, ảnh đĩa hoặc tài liệu mật, việc so sánh checksum của tệp với digest đã được nhà cung cấp công bố xác nhận rằng tệp không bị thay đổi trong quá trình truyền hoặc bị hỏng do mất kết nối mạng.

## Công Cụ Kiểm Tra Checksum Trên Dòng Lệnh Các Nền Tảng

Mọi hệ điều hành lớn đều cung cấp công cụ tích hợp để tính toán và xác minh hash.

### 1. macOS (Terminal)
```bash
# Tính SHA-256
shasum -a 256 sample-10mb.pdf

# Tính MD5
md5 sample-10mb.pdf
```

### 2. Linux (Ubuntu, Debian, RedHat)
```bash
# Tính SHA-256
sha256sum sample-10mb.pdf

# Xác minh với file checksums.txt
sha256sum -c checksums.txt
```

### 3. Windows (PowerShell)
```powershell
# Tính SHA-256
Get-FileHash .\sample-10mb.pdf -Algorithm SHA256

# Tính MD5
Get-FileHash .\sample-10mb.pdf -Algorithm MD5
```

## Tự Động Hóa Xác Minh Checksum Trong Node.js

```typescript
import fs from 'fs';
import crypto from 'crypto';

export async function verifyDownloadedFile(
  filePath: string,
  expectedChecksum: string,
  algorithm = 'sha256'
): Promise<boolean> {
  const hash = crypto.createHash(algorithm);
  const stream = fs.createReadStream(filePath);

  for await (const chunk of stream) {
    hash.update(chunk);
  }

  const actualChecksum = hash.digest('hex').toLowerCase();
  const matches = actualChecksum === expectedChecksum.toLowerCase();

  if (!matches) {
    console.error(`Sai tính toàn vẹn! Mong đợi: ${expectedChecksum}, nhận được: ${actualChecksum}`);
  }

  return matches;
}
```

## Tại Sao Cần Xác Minh Qua HTTPS?
Mặc dù TLS mã hóa dữ liệu trong quá trình truyền, một mạng phân phối nội dung bị xâm phạm, cache proxy bị lỗi hoặc kết nối bị gián đoạn có thể dẫn đến các payload bị cắt ngắn hoặc độc hại. Công bố SHA-256 digest ngoài băng tần đảm bảo tính xác thực đầu cuối.
