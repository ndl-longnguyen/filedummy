Khi kiểm thử các thao tác tệp phức tạp — như quét thư mục đệ quy, giải nén zip lồng nhau hoặc ghi đè tệp nguyên tử — việc mock từng phương thức `fs` riêng lẻ bằng `jest.fn()` nhanh chóng trở nên mong manh. `memfs` cung cấp một filesystem ảo hoàn chỉnh, trong bộ nhớ cho các bài test Jest.

## Tại Sao Sử Dụng memfs Để Kiểm Thử Thao Tác Tệp?

`memfs` triển khai hoàn toàn API `fs` và `fs/promises` của Node.js trong RAM:
- **Cực nhanh:** Không có I/O đĩa vật lý, tăng tốc test suite lớn lên đến 10 lần.
- **Không ô nhiễm test:** Không còn thư mục tạm bị bỏ lại sau khi test thất bại.
- **Xác định:** Dễ dàng cấu hình cây tệp chính xác trước mỗi test.

## Thiết Lập memfs Với Jest

Trước tiên cài đặt `memfs`:
```bash
npm install --save-dev memfs
```

Tạo file mock trong `__mocks__/fs.js` hoặc cấu hình trực tiếp Jest để mock `fs` và `fs/promises`:

```typescript
import { fs, vol } from 'memfs';
import { backupUserFiles } from '../src/backupService';

// Chuyển hướng các lời gọi node fs sang memfs virtual volume
jest.mock('fs', () => fs);
jest.mock('fs/promises', () => fs.promises);

describe('Backup Service Với Filesystem Trong Bộ Nhớ', () => {
  beforeEach(() => {
    // Reset virtual filesystem trước mỗi test
    vol.reset();
  });

  it('nén các tệp mục tiêu vào thư mục đích', async () => {
    // Tạo cây thư mục ảo
    vol.fromJSON({
      '/app/data/file1.txt': 'Hello World',
      '/app/data/file2.json': '{"active": true}',
      '/app/backups': null, // thư mục rỗng
    });

    await backupUserFiles('/app/data', '/app/backups');

    // Kiểm tra các tệp đã được tạo trên đĩa ảo
    const backupFiles = fs.readdirSync('/app/backups');
    expect(backupFiles).toContain('file1.txt');
    expect(backupFiles).toContain('file2.json');
  });
});
```

## Checklist Tóm Tắt
- Sử dụng `vol.fromJSON()` để mock nhanh toàn bộ cây thư mục trong một lời gọi.
- Luôn gọi `vol.reset()` trong `beforeEach` để đảm bảo sự cô lập test sạch.
- Kết hợp `memfs` với các bộ tạo tệp tùy chỉnh để mô phỏng các trường hợp edge như cấu trúc thư mục lồng sâu và lỗi quyền truy cập.
