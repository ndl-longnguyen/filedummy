Một trong những nguồn gây lỗi phổ biến nhất trong xác thực tệp là sự nhầm lẫn giữa đơn vị kích thước thập phân (SI, cơ số 10) và nhị phân (IEC, cơ số 2). Biết liệu máy chủ hoặc nhà cung cấp đám mây của bạn tính 1MB là 1.000.000 byte hay 1.048.576 byte sẽ ngăn chặn các lỗi ranh giới khó phát hiện.

## Tiền Tố Thập Phân (SI) vs Nhị Phân (IEC)

| Đơn vị | Tiền tố | Cơ số 10 (Thập phân / Ổ cứng / S3) | Tiền tố nhị phân | Cơ số 2 (RAM / OS / Windows) |
|--------|---------|--------------------------------------|------------------|-------------------------------|
| Kilo | KB | 1.000 byte (`10^3`) | KiB | 1.024 byte (`2^10`) |
| Mega | MB | 1.000.000 byte (`10^6`) | MiB | 1.048.576 byte (`2^20`) |
| Giga | GB | 1.000.000.000 byte (`10^9`) | GiB | 1.073.741.824 byte (`2^30`) |

## Hàm Định Dạng Kích Thước Tệp Chính Xác Bằng TypeScript

```typescript
export function formatBytes(bytes: number, decimals = 2, useBinary = true): string {
  if (bytes === 0) return '0 Bytes';

  const k = useBinary ? 1024 : 1000;
  const dm = decimals < 0 ? 0 : decimals;
  const sizes = useBinary
    ? ['Bytes', 'KiB', 'MiB', 'GiB', 'TiB']
    : ['Bytes', 'KB', 'MB', 'GB', 'TB'];

  const i = Math.floor(Math.log(bytes) / Math.log(k));

  return `${parseFloat((bytes / Math.pow(k, i)).toFixed(dm))} ${sizes[i]}`;
}

// Ví dụ kết quả:
// formatBytes(1048576, 2, true)  => "1 MiB"
// formatBytes(1000000, 2, false) => "1 MB"
```

## Lời Khuyên Thực Tiễn Cho Quy Tắc Tải Lên Tệp
Khi cấu hình giới hạn tải lên trong ứng dụng web, hãy sử dụng rõ ràng **byte** thô trong schema cấu hình (ví dụ: `maxSizeBytes: 10485760`) thay vì chuyển đổi chuỗi động.
