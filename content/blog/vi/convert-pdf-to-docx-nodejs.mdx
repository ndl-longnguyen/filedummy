Chuyển đổi tài liệu PDF sang tệp Microsoft Word (.docx) có thể chỉnh sửa là yêu cầu phổ biến trong các cổng pháp lý, nền tảng xem xét hợp đồng và hệ thống quản lý tài liệu. Vì PDF về cơ bản là định dạng hiển thị (xác định tọa độ glyph tuyệt đối) chứ không phải cấu trúc ngữ nghĩa, việc chuyển đổi đòi hỏi tái cấu trúc.

## Các Phương Pháp Chuyển Đổi Trong Node.js

1. **LibreOffice Headless (Tự lưu trữ):** Độ trung thực cao, chuyển đổi bảng phức tạp và bố cục qua dòng lệnh.
2. **Cloud Converter API (ConvertAPI, CloudConvert):** Không cần bảo trì, xử lý OCR và văn bản được rasterize.
3. **pdf2docx (Python bridge qua Node child_process):** Chất lượng cao cho tài liệu vector và bảng biểu.

## Sử Dụng Headless LibreOffice Với Node.js

Chạy LibreOffice ở chế độ headless trong Docker container cung cấp khả năng chuyển đổi tài liệu miễn phí, đáng tin cậy:

```typescript
import { exec } from 'child_process';
import util from 'util';
import path from 'path';
import fs from 'fs';

const execPromise = util.promisify(exec);

export async function convertPdfToDocx(inputPdfPath: string, outputDir: string): Promise<string> {
  if (!fs.existsSync(inputPdfPath)) {
    throw new Error('Tệp PDF đầu vào không tồn tại.');
  }

  // soffice là tên thực thi cho LibreOffice
  const cmd = `soffice --headless --convert-to docx "${inputPdfPath}" --outdir "${outputDir}"`;

  console.log('Đang thực thi chuyển đổi:', cmd);
  const { stdout, stderr } = await execPromise(cmd);

  if (stderr && !stderr.includes('Warning')) {
    console.warn('Cảnh báo LibreOffice:', stderr);
  }

  const baseName = path.basename(inputPdfPath, path.extname(inputPdfPath));
  const expectedOutputPath = path.join(outputDir, `${baseName}.docx`);

  if (!fs.existsSync(expectedOutputPath)) {
    throw new Error('Chuyển đổi hoàn tất nhưng tệp DOCX đầu ra không được tạo.');
  }

  return expectedOutputPath;
}
```

## Các Thách Thức Chuyển Đổi Chính
- **Font nhúng:** Thiếu font hệ thống có thể gây ra lỗi chồng chữ và reflow. Cài đặt Microsoft Core Fonts chuẩn (`msttcorefonts`) trên host Linux/Docker của bạn.
- **Trang được quét:** PDF chỉ chứa ảnh raster đòi hỏi bước Nhận dạng Ký tự Quang học (OCR) bằng Tesseract trước khi chuyển đổi.
