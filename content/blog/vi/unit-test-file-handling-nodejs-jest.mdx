Kiểm thử đơn vị code đọc, ghi, chuyển đổi hoặc xác thực tệp trong Node.js đòi hỏi sự cô lập cẩn thận để ngăn chặn ô nhiễm dữ liệu kiểm thử, I/O chậm và lỗi đường dẫn phụ thuộc nền tảng. Dưới đây là các chiến lược thực tiễn để kiểm thử logic tệp với Jest.

## Kiểm Thử Xử Lý Buffer Và Stream

Khi kiểm thử đơn vị các bộ phân tích hoặc chuyển đổi tệp, hãy tránh đọc từ filesystem vật lý. Truyền trực tiếp Buffer trong bộ nhớ hoặc Readable stream.

```typescript
import { parseCsvBuffer } from '../src/csvParser';

describe('Unit Test Xử Lý CSV', () => {
  it('phân tích dữ liệu CSV hợp lệ thành các bản ghi có cấu trúc', async () => {
    const mockCsvContent = 'id,name,role\n1,Alice,Admin\n2,Bob,Developer';
    const buffer = Buffer.from(mockCsvContent, 'utf-8');

    const result = await parseCsvBuffer(buffer);

    expect(result).toHaveLength(2);
    expect(result[0]).toEqual({ id: '1', name: 'Alice', role: 'Admin' });
  });

  it('ném ValidationError khi buffer rỗng', async () => {
    const emptyBuffer = Buffer.alloc(0);

    await expect(parseCsvBuffer(emptyBuffer)).rejects.toThrow('File cannot be empty');
  });
});
```

## Mock Module `fs/promises` Của Node.js

Đối với các hàm tương tác trực tiếp với đĩa, sử dụng khả năng mock module của Jest:

```typescript
import * as fs from 'fs/promises';
import { readConfigSafely } from '../src/fileConfig';

jest.mock('fs/promises');

describe('readConfigSafely', () => {
  afterEach(() => {
    jest.clearAllMocks();
  });

  it('trả về cấu hình đã phân tích khi tệp tồn tại', async () => {
    (fs.readFile as jest.Mock).mockResolvedValue(JSON.stringify({ maxUploadSize: 10485760 }));

    const config = await readConfigSafely('/etc/app/config.json');
    expect(config.maxUploadSize).toBe(10485760);
    expect(fs.readFile).toHaveBeenCalledWith('/etc/app/config.json', 'utf-8');
  });
});
```

## Các Quy Tắc Tốt Nhất Cho Unit Test Tệp
1. **Không commit binary lớn vào git:** Giữ các tệp fixture kiểm thử nhỏ (&lt;50KB) hoặc tạo chúng theo cách xác định.
2. **Sử dụng thư mục tạm:** Khi không thể tránh ghi đĩa, ghi vào `os.tmpdir()` và dọn sạch trong `afterAll`.
3. **Kiểm tra tính toàn vẹn nhị phân:** Sử dụng so sánh checksum để xác nhận các bộ chuyển đổi tệp xuất ra nội dung hợp lệ.
