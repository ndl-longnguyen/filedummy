## Trích Xuất HTML Ngữ Nghĩa và Markdown Trong Node.js

```typescript
import mammoth from 'mammoth';
import fs from 'fs';

export async function convertDocxToHtml(filePath: string): Promise<string> {
  const buffer = fs.readFileSync(filePath);

  const result = await mammoth.convertToHtml({ buffer }, {
    styleMap: [
      "p[style-name='Heading 1'] => h1:fresh",
      "p[style-name='Heading 2'] => h2:fresh",
      "p[style-name='Lead'] => p.lead:fresh",
      "r[style-name='Emphasis'] => em",
    ],
  });

  if (result.messages.length > 0) {
    console.log('Cảnh báo chuyển đổi Mammoth:', result.messages);
  }

  return result.value; // Chuỗi HTML đã được render
}

export async function extractRawDocxText(filePath: string): Promise<string> {
  const buffer = fs.readFileSync(filePath);
  const result = await mammoth.extractRawText({ buffer });
  return result.value;
}
```

## Phân Tích DOCX Trực Tiếp Trên Trình Duyệt

Mammoth chạy được trực tiếp trên trình duyệt sử dụng `FileReader`:

```typescript
import mammoth from 'mammoth';

export async function parseDocxFileInBrowser(file: File): Promise<string> {
  const arrayBuffer = await file.arrayBuffer();
  const { value: html } = await mammoth.convertToHtml({ arrayBuffer });
  return html;
}
```

## Ưu Điểm Của Mammoth So Với Regex Thủ Công
- **Cấu trúc ngữ nghĩa:** Chuyển đổi kiểu đoạn văn Word thành các thẻ `<h1>`, `<p>`, và `<ul>` thực sự thay vì các span có inline style.
- **Đầu ra HTML an toàn:** Tự động làm sạch đầu ra và mã hóa ký tự đặc biệt để ngăn chặn tấn công stored XSS.
