Khi tải lên các tài sản lớn như tài liệu, video hoặc tập dữ liệu thô, cung cấp phản hồi trực quan bằng thanh tiến trình chính xác là điều thiết yếu cho trải nghiệm người dùng. Mặc dù Fetch API hiện đại không hiển thị sự kiện tiến trình tải lên, XMLHttpRequest (XHR) và Streams API của trình duyệt cung cấp khả năng kiểm soát đầy đủ.

## Tại Sao Fetch API Thiếu Tiến Trình Tải Lên

Fetch API được thiết kế xung quanh WHATWG Streams. Mặc dù streaming request body ngày càng được hỗ trợ trong một số trình duyệt hiện đại, `fetch()` vẫn không cung cấp callback `onUploadProgress` chuẩn hóa.

Để theo dõi số byte gửi đi qua mạng, **XMLHttpRequest** vẫn là tiêu chuẩn ngành.

## Xây Dựng Component Thanh Tiến Trình Tải Lên

Dưới đây là triển khai hoàn chỉnh, sạch sẽ bằng TypeScript hiện đại:

```typescript
export function uploadWithProgress(
  file: File,
  url: string,
  onProgress: (percent: number, loaded: number, total: number) => void
): Promise<string> {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();

    // Lắng nghe sự kiện tiến trình tải lên
    xhr.upload.addEventListener('progress', (event) => {
      if (event.lengthComputable) {
        const percent = Math.round((event.loaded / event.total) * 100);
        onProgress(percent, event.loaded, event.total);
      }
    });

    xhr.addEventListener('load', () => {
      if (xhr.status >= 200 && xhr.status < 300) {
        resolve(xhr.responseText);
      } else {
        reject(new Error(`HTTP ${xhr.status}: ${xhr.statusText}`));
      }
    });

    xhr.addEventListener('error', () => reject(new Error('Lỗi mạng trong quá trình tải lên')));
    xhr.addEventListener('abort', () => reject(new Error('Tải lên bị hủy bởi người dùng')));

    const formData = new FormData();
    formData.append('file', file);

    xhr.open('POST', url, true);
    xhr.send(formData);
  });
}
```

## Các Mẹo Thực Tiễn
- **Tính toán tốc độ truyền:** Đo `event.loaded - lastLoaded` mỗi giây để hiển thị tốc độ tải lên động bằng MB/s và thời gian dự kiến còn lại (ETA).
- **Xử lý tạm dừng nhân tạo:** Trình duyệt kích hoạt sự kiện 100% cuối cùng khi tất cả byte rời khỏi socket client, nhưng máy chủ có thể mất thêm vài giây để quét hoặc lưu tệp trước khi gửi HTTP 200. Hiển thị trạng thái "Đang xử lý..." giữa 100% và khi nhận được response.
