Bảo mật endpoint tải lên tệp đòi hỏi xác thực nghiêm ngặt. Chấp nhận tệp không được xác thực khiến máy chủ bị lộ trước tấn công từ chối dịch vụ (hết đĩa), thực thi code từ xa (RCE) và cross-site scripting (XSS). Hướng dẫn này trình bày xác thực hai tầng cả phía frontend và backend.

## Quy Tắc Xác Thực Hai Tầng

- **Phía Client:** Cung cấp phản hồi tức thì và tiết kiệm băng thông client. Không bao giờ tin tưởng xác thực client cho mục đích bảo mật.
- **Phía Server:** Rào cản thực sự. Xác minh kích thước tệp, magic byte nội dung thực tế và làm sạch tên tệp trước khi lưu vào đĩa hoặc object storage.

## Xác Thực Phía Client (React / Vanilla JS)

```typescript
const ALLOWED_MIME_TYPES = ['application/pdf', 'image/jpeg', 'image/png'];
const MAX_FILE_SIZE = 25 * 1024 * 1024; // 25MB

export function validateFileBeforeUpload(file: File): { valid: boolean; error?: string } {
  if (file.size === 0) {
    return { valid: false, error: 'Tệp rỗng (0 byte).' };
  }

  if (file.size > MAX_FILE_SIZE) {
    return {
      valid: false,
      error: `Kích thước tệp (${(file.size / (1024 * 1024)).toFixed(1)}MB) vượt quá giới hạn 25MB.`,
    };
  }

  if (!ALLOWED_MIME_TYPES.includes(file.type)) {
    return {
      valid: false,
      error: 'Định dạng tệp không hợp lệ. Chỉ cho phép PDF, JPG và PNG.',
    };
  }

  return { valid: true };
}
```

## Xác Thực Phía Server Trong Express / Node.js

Luôn áp dụng giới hạn trong middleware để các request quá kích thước bị từ chối trước khi tiêu thụ RAM máy chủ:

```typescript
import express from 'express';
import multer from 'multer';

const upload = multer({
  limits: {
    fileSize: 25 * 1024 * 1024, // tối đa 25 MB
    files: 1,
  },
  fileFilter: (req, file, cb) => {
    const allowedTypes = ['application/pdf', 'image/jpeg', 'image/png'];
    if (!allowedTypes.includes(file.mimetype)) {
      return cb(new Error('LIMIT_UNEXPECTED_FILETYPE'));
    }
    cb(null, true);
  },
});

const app = express();

app.post('/api/upload', upload.single('document'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ error: 'Không có tệp nào được tải lên' });
  }

  res.status(200).json({
    message: 'Tệp đã được xác thực và nhận thành công',
    filename: req.file.originalname,
    size: req.file.size,
  });
});
```

## Danh Sách Kiểm Tra Bảo Mật
1. **Làm sạch tên tệp:** Loại bỏ các ký tự path traversal (`..`, `/`, `\`) và byte kiểm soát unicode.
2. **Không thực thi tại chỗ:** Lưu tệp tải lên ngoài web server root hoặc trong object storage (S3/R2).
3. **Ngẫu nhiên hóa khóa lưu trữ:** Lưu dưới dạng UUID (ví dụ: `uuidv4() + '.pdf'`) thay vì tên tệp do người dùng cung cấp.
