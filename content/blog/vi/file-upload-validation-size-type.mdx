Securing file upload endpoints requires rigorous validation. Accepting unvalidated files exposes servers to denial-of-service (disk exhaustion), remote code execution (RCE), and cross-site scripting (XSS). This tutorial demonstrates two-tier validation on both frontend and backend.

## The Rule of Dual Validation

- **Client-Side:** Provides immediate feedback and saves client bandwidth. Never trust client validation for security.
- **Server-Side:** The true barrier. Verifies file size, actual content magic bytes, and sanitizes filenames before saving to disk or object storage.

## Client-Side Validation (React / Vanilla JS)

```typescript
const ALLOWED_MIME_TYPES = ['application/pdf', 'image/jpeg', 'image/png'];
const MAX_FILE_SIZE = 25 * 1024 * 1024; // 25MB

export function validateFileBeforeUpload(file: File): { valid: boolean; error?: string } {
  if (file.size === 0) {
    return { valid: false, error: 'File is empty (0 bytes).' };
  }

  if (file.size > MAX_FILE_SIZE) {
    return {
      valid: false,
      error: `File size (${(file.size / (1024 * 1024)).toFixed(1)}MB) exceeds 25MB limit.`,
    };
  }

  if (!ALLOWED_MIME_TYPES.includes(file.type)) {
    return {
      valid: false,
      error: 'Invalid file format. Only PDF, JPG, and PNG are permitted.',
    };
  }

  return { valid: true };
}
```

## Server-Side Validation in Express / Node.js

Always enforce limits in your middleware layer so oversized requests are rejected before consuming server RAM:

```typescript
import express from 'express';
import multer from 'multer';

const upload = multer({
  limits: {
    fileSize: 25 * 1024 * 1024, // 25 MB max
    files: 1,
  },
  fileFilter: (req, file, cb) => {
    const allowedTypes = ['application/pdf', 'image/jpeg', 'image/png'];
    if (!allowedTypes.includes(file.mimetype)) {
      return cb(new Error('LIMIT_UNEXPECTED_FILETYPE'));
    }
    cb(null, true);
  },
});

const app = express();

app.post('/api/upload', upload.single('document'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ error: 'No file uploaded' });
  }

  res.status(200).json({
    message: 'File successfully validated and received',
    filename: req.file.originalname,
    size: req.file.size,
  });
});
```

## Security Checklist
1. **Sanitize filenames:** Strip path traversal characters (`..`, `/`, `\`) and unicode control bytes.
2. **Do not execute in place:** Store uploads outside the web server root or in object storage (S3/R2).
3. **Randomize storage keys:** Save as UUIDs (e.g. `uuidv4() + '.pdf'`) instead of the user-supplied filename.
