MIME type (Multipurpose Internet Mail Extensions), được IANA chuẩn hóa, hướng dẫn trình duyệt web và HTTP client cách diễn giải và hiển thị các luồng byte nhận được. Đặt MIME type không đúng dẫn đến tệp tải xuống dưới dạng văn bản thuần túy, luồng video bị hỏng hoặc các lỗ hổng bảo mật như tấn công MIME-sniffing.

## Bảng MIME Type Web Phổ Biến

| Phần mở rộng | MIME Type | Mô tả |
|--------------|-----------|-------|
| `.pdf` | `application/pdf` | Tài liệu PDF Adobe |
| `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | Microsoft Word |
| `.json` | `application/json` | JavaScript Object Notation |
| `.csv` | `text/csv` | Giá Trị Phân Cách Bằng Dấu Phẩy |
| `.zip` | `application/zip` | Archive ZIP |
| `.png` | `image/png` | Đồ Họa Mạng Di Động |
| `.jpg` | `image/jpeg` | Hình Ảnh JPEG |
| `.txt` | `text/plain` | Văn Bản Thuần Túy |

## Áp Dụng Content-Type Trong HTTP Headers

```http
HTTP/1.1 200 OK
Content-Type: application/pdf
Content-Disposition: inline; filename="statement.pdf"
X-Content-Type-Options: nosniff
```

## Header `X-Content-Type-Options: nosniff` Quan Trọng
Các trình duyệt cũ cố gắng "ngửi" nội dung tệp bất kể `Content-Type` header khai báo gì. Kẻ tấn công có thể tải lên tệp HTML chứa JavaScript được giả mạo với header `text/plain`; trình duyệt sẽ phát hiện thẻ HTML và thực thi script độc hại (Cross-Site Scripting).

Đặt `X-Content-Type-Options: nosniff` ra lệnh cho trình duyệt tin tưởng MIME type đã khai báo và từ chối thực thi các tệp không phải thực thi.
