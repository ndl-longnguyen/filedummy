Parsing Microsoft Word (.docx) documents into clean HTML or Markdown is essential for content management systems, resume parsers, and blog importers. The `mammoth.js` library converts OpenXML documents with a focus on semantic HTML elements.

## Installing mammoth

```bash
npm install mammoth
```

## Extracting Semantic HTML and Markdown in Node.js

```typescript
import mammoth from 'mammoth';
import fs from 'fs';

export async function convertDocxToHtml(filePath: string): Promise<string> {
  const buffer = fs.readFileSync(filePath);

  const result = await mammoth.convertToHtml({ buffer }, {
    styleMap: [
      "p[style-name='Heading 1'] => h1:fresh",
      "p[style-name='Heading 2'] => h2:fresh",
      "p[style-name='Lead'] => p.lead:fresh",
      "r[style-name='Emphasis'] => em",
    ],
  });

  if (result.messages.length > 0) {
    console.log('Mammoth conversion warnings:', result.messages);
  }

  return result.value; // The rendered HTML string
}

export async function extractRawDocxText(filePath: string): Promise<string> {
  const buffer = fs.readFileSync(filePath);
  const result = await mammoth.extractRawText({ buffer });
  return result.value;
}
```

## Parsing DOCX in the Browser

Mammoth runs natively in the browser using `FileReader`:

```typescript
import mammoth from 'mammoth';

export async function parseDocxFileInBrowser(file: File): Promise<string> {
  const arrayBuffer = await file.arrayBuffer();
  const { value: html } = await mammoth.convertToHtml({ arrayBuffer });
  return html;
}
```

## Advantages of Mammoth Over Raw Regex
- **Semantic structure:** Converts Word paragraph styles to true `<h1>`, `<p>`, and `<ul>` tags instead of inline styling spans.
- **Safe HTML output:** Automatically sanitizes output and encodes special characters to prevent stored XSS attacks.
